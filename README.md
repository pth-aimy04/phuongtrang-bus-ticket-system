# Phuong Trang Bus Ticket System

Online bus ticket booking and management system for Phuong Trang Bus Company.  
This project was developed as a university project to simulate the ticket booking and management process of a passenger transport company.

---

## Overview

The system allows customers to:
- Register and log in
- Search for bus trips by departure, destination, and date
- Select seats
- Book tickets online
- View booking information

The system also provides an admin panel to:
- Manage routes, trips, vehicles, and tickets
- Manage user accounts
- Monitor and report revenue

---

## Features

### Customer
- User registration and login  
- Search trips  
- Seat selection  
- Ticket booking  
- View booking details  

### Admin
- Manage routes  
- Manage trips  
- Manage vehicles  
- Manage tickets  
- Manage users  
- View reports  

---

## Tech Stack

- Frontend: ReactJS  
- Backend: NodeJS, ExpressJS  
- Database: SQL Server  
- Authentication: JWT  

---

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```
